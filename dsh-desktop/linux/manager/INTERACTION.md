# dsh-manager 界面说明：每个按键做什么、什么状态、有什么动效

> 这份文件是**行为规格**（spec），不是使用手册：
>
> - 你（或任何接手的人）改界面/交互时，以这份为准对照；
> - 验收时按 §9 的清单逐条勾；
> - 视觉的"长什么样"看 `design/`（Kimi 的设计稿）与 `HANDOFF-PROMPT.md` 的分区比对；
>   这里回答的是"**点了会发生什么、动效是什么**"。
>
> 代码位置一律相对 `manager/dsh_manager/gui.py`，除非另注。样式一律在
> `tools/gtk-theme-template.css.in`（生成 14 份主题 CSS，**不要手改生成物**）。

## 0. 通用约定

| 约定 | 值 / 说明 |
| --- | --- |
| 主题与模式 | 7 套主题（`frost` 毛玻璃 / `liquid` 液态玻璃 / `crystal` 水晶 / `flat` 扁平化 / `alpine` 雪山 / `dawn` 晨光 / `sea` 静海）× 日/夜 |
| 配置存储 | `~/.config/dsh-manager/settings.json`：`theme`、`mode`（`day`/`night`）、`logLines` |
| 状态枚举 | `running` 运行中 / `starting` 启动中 / `external` 端口有服务（非本管理器）/ `stopped` 已停止 / `broken` 不完整（需修复） |
| 选中语义 | 左侧实例行被选中 → 右侧所有卡片显示该实例；无选中时依赖实例的按钮全部禁用 |
| 忙碌语义 | `self.busy = True` 期间：顶部出现脉冲进度条、**除进度外所有按钮禁用**（防并发操作） |
| 统一过渡 | 交互控件 hover/press：`background-color`、`color`、`border-color`、`box-shadow` 各 **160ms ease-out** |
| 禁用态 | 按钮变灰且**不响应点击**；禁用原因通常是"没选实例"或"正在忙" |
| 键盘 | 菜单/对话框使用 GTK 原生键盘行为（Tab 切换焦点、Esc 关闭 popover/对话框、空格/回车激活） |

### 动效怎么实现（含"看起来做不到"的那几个）

设计稿里的效果**都有路子**，细节与代码骨架见 `HANDOFF-PROMPT.md` §6（效果攻坚手册）：

| 设计稿效果 | 可行的实现路径 | 需要装的依赖 |
| --- | --- | --- |
| 真毛玻璃（`backdrop-filter`） | 背景是我们自己的静态 PNG：按控件 allocation 裁剪 → 高斯模糊（缓存）→ cairo 圆角裁切绘制 + 主题色叠加 | `python3-pil`、`python3-numpy`、`python3-cairo`、`python3-gi-cairo` |
| hover 上浮 / 缩放 / 位移（`transform`） | 控件 `draw` 里 `cr.translate()` + `GLib.timeout_add(16)` 跑 160ms ease-out 插值；或用 `Gtk.Fixed`+`move()` | `python3-cairo`、`python3-gi-cairo` |
| 设计稿的 SVG 图标 | 从 `design/index.html` 的 24 个 `<symbol>` 导出 `icons/*.svg`，`GdkPixbuf`/`Gtk.Image` 加载（日/夜各一套颜色） | `librsvg2-common` |
| 字体与字宽 | 装 `fonts-inter`（最接近 Segoe UI）+ `fonts-noto-cjk`，CSS 里换 `font-family`，必要时微调 `font-size` 小数 | `fonts-inter`、`fonts-noto-cjk` |
| 主题切换过渡 | 抓窗口快照放进 `Gtk.Overlay`，换主题后用 cairo `paint_with_alpha` 淡出 | `python3-cairo` |
| 色块 / 圆点 / 药丸背景 | 用 `Gtk.EventBox`（代码里的 `_chip()`）或 `Gtk.DrawingArea` 自绘 | — |
| 布局（flex/grid） | `Gtk.Grid` / `Gtk.Box` / `Gtk.FlowBox` / `Gtk.Overlay` | — |
| CSS 变量 | 生成器把令牌写成字面量（现状），或用 `@define-color` + `alpha()` | — |

> 这些是"难"不是"不能"。真试不出来时，按 PROMPT §6.7 记录：试过什么 / 失败症状 /
> 还缺什么（依赖、GTK4、上游修复）。**不接受"GTK 不支持所以跳过"这种结论。**

## 1. 窗口与外壳

| 项 | 规格 |
| --- | --- |
| 窗口 | 无系统标题栏（`set_titlebar(None)`），内容自绘；背景 = 当前主题的预渲染背景图（`backgrounds/<主题>-<日/夜>.png`），`cover` 铺满 |
| 外壳 | 距窗口边 `18px` 的圆角卡片（`.dsh-shell`）：半透明底 + 1px 边框 + 大阴影；圆角随主题（水晶 20 / 扁平 14 / 晨光 28 …） |
| 初始尺寸 | 设计稿画布 1440×900；屏幕放不下时按工作区收缩（留 60px），**不设最小尺寸**（想缩多小由用户拖） |
| 内容滚动 | 两个页面各自滚动；**打开/刷新后强制滚回顶部**（否则标题区会被顶栏压住） |
| 分隔 | 侧栏与主区之间 1px 内边框；顶栏底部 1px 内边框 |

动效：窗口缩放无自定义动画（GTK 原生）；主题/日夜切换是**瞬间完成**（重载 CSS，无过渡）。

## 4. 仪表盘页（`.content`）

### 4.1 页面标题区

| 控件 | 说明 |
| --- | --- |
| `INSTANCE OVERVIEW`（eyebrow） | 只读，小写字距 |
| 实例名（h1） | 随选中实例变化；未选中显示「选择左侧的实例」 |
| **状态徽标** | `running` 绿（半透明绿底 + 绿字）；`broken` 红；其它灰。**不是**彩色圆点，是胶囊 |
| 描述一句话 | 只读 |
| **打开窗口**（主按钮，`↗`） | 见 §4.2 |
| `⋯` 更多 | 展开 popover（见 §4.2） |

### 4.2 顶部动作

| 控件 | 点击后发生什么 | 状态 / 动效 |
| --- | --- | --- |
| **打开窗口** | ① 先确保服务在跑（没跑就起）；② 窗口已在 → **提到前台 + 补一次整窗重绘**；窗口不在 → 启动窗口；③ 失败 → 日志给出启动器退出码 + `logs/desktop.log` 末尾 | 主按钮：渐变（主题强调色）+ 阴影；hover 阴影加深；无选中/忙时禁用。**不弹确认** |
| `⋯ 更多` 菜单 | ① 查看 Token ② 重建窗口 ③ 在文件管理器中显示 ④ ─── 分隔线 ─── ⑤ 卸载实例（红字） | 菜单圆角 14 + 阴影；行 hover 浅底；卸载行文字/图标红 |

### 4.3 实例信息卡（只读）

| 项 | 说明 |
| --- | --- |
| 大 avatar | 实例名前两位，渐变底白字 |
| 名称 / 路径 | 路径可选中复制；长路径省略号 + tooltip |
| `dsh x.y.z` / `Node x.y.z` 胶囊 | 只读 |
| 三个指标：进程 PID / 服务端口 / 运行状态 | 三个等宽列，**列间有 1px 竖分隔线**；运行状态用强调色（绿） |

### 4.4 快捷控制卡

| 控件 | 点击后发生什么 | 状态 |
| --- | --- | --- |
| `▶ 启动`（服务） | 后台起 `dsh web --no-open --port <端口>`；日志逐步输出；完成后状态变运行中 | **仅当实例 stopped 且未忙时可用**；运行中禁用 |
| `■ 停止`（服务，红色软底） | 停服务（SIGTERM → 超时 SIGKILL）；状态变已停止 | 仅当有运行 PID 时可用 |
| `↺ 重载`（窗口） | 让窗口重新加载页面（发 `reload`）；旧版窗口会答 `unknown` → 日志提示"请点重建窗口" | 需选中实例 |
| `↻ 重建`（窗口） | 杀窗口进程 → 清 `/tmp/dsh-desktop-<端口>.lock*` → 重开；**服务与会话不动** | 需选中实例 |
| 右上 `● 服务正常 / ● 未运行` | 只读指示灯（绿/灰） | 随状态刷新（4 秒轮询） |

### 4.5 常用功能（4 格）

| 格子 | 点击后发生什么 | 动效 |
| --- | --- | --- |
| **查看 Token**（⚿） | 从日志取**最新**一条 `dsh web: …?token=…`，先请求一次判状态（200 可用 / 401 过期 / 连不上），结果**打印在下方日志区并复制到剪贴板**；token 不落盘 | hover：浅底 + 边框转强调色 + 阴影抬起（替代上浮） |
| **管理插件**（⊞） | 打开插件对话框：列出我们 GitHub 仓库的插件、对当前实例安装/卸载；装完提示重启服务 | 同上 |
| **检查更新**（↓） | 打开「更新 <实例>」对话框：dsh/Node 版本选择（下拉 + 手动 + 更新按钮）→ 更新 | 同上 |
| **数据目录**（▤） | `xdg-open <实例前缀>`（文件管理器） | 同上 |

### 4.6 最近日志卡

| 项 | 规格 |
| --- | --- |
| 条数 | 最多 **3** 条，**新的在最上** |
| 每行 | `HH:MM:SS`（灰）+ 等级胶囊 + 正文（省略号 + tooltip 全文） |
| 等级胶囊 | `✔` 成功（绿）/ `✘` 失败（红）/ `——` 系统（灰）/ 其它 信息（强调色） |
| 计数胶囊 | 当前条数 |
| 空态 | 显示「还没有日志」，不占三行空白 |
| **查看完整日志 →** | 打开对话框：顶部写明「本次运行 N 行 / 文件最后 400 行」，正文含【本次运行】与【已落盘】两段；文字区**必须填满对话框**（不是两行） |
| 动效 | 新行直接插入（无动画）；对话框打开无自定义动画 |

### 4.7 页脚

只读：左「● 所有更改已自动保存」、右「实例根目录 · <路径>」。

## 6. 反馈组件

| 组件 | 触发 | 动效 / 时长 |
| --- | --- | --- |
| **toast**（底部居中气泡） | 主题切换、日夜切换、复制诊断、保存设置 | `Gtk.Revealer` SLIDE_UP 出现；**2.6 秒**后自动收起 |
| **忙碌进度条**（顶栏下方） | 安装/更新/修复/重建/打开窗口等耗时操作 | 脉冲式（110ms/帧，类似 Win7 滚动条）+ 一行说明文字；期间按钮全禁用 |
| **对话框**（关于/帮助/日志/插件/更新/新建） | 各自按钮 | 尺寸按主窗口 **72% 宽 / 80% 高**，夹进屏幕工作区；打开无自定义动画；Esc 关闭 |
| **确认框** | 卸载实例 | 模态 OK/Cancel；取消无副作用 |
| **禁用态** | 无选中实例 / 忙碌中 | 变灰、不响应 |

## 7. 对话框里的控件（逐项）

### 7.1 新建实例

| 控件 | 功能 |
| --- | --- |
| 安装目录 + `浏览…` | 选目录；显示名称自动跟随目录名 |
| 显示名称 | 列表里显示的名字 |
| 端口（SpinButton） | 1024–65535；默认取第一个空闲端口 |
| **dsh 版本** = 下拉框 + 手动输入框 + **`更新`** | 打开即带预设（`latest` + 5 个内置版本）；`更新` 联网刷新并**覆盖**列表（失败只改 tooltip，不清空）；手动输入优先级最高 |
| Node 版本 | 同上（4 个内置 LTS） |
| `取消` / `安装` | 取消无副作用；安装→忙碌条+日志→完成后刷新实例列表 |

### 7.2 更新实例 / 插件 / 关于 / 帮助 / 日志

- 更新实例：与新建同款版本选择器（带 `更新`）+ `取消`/`更新`；
- 管理插件：表格（插件 / 仓库说明 / 状态 / 版本）+ 安装/卸载按钮 + `关闭`；
- 关于/帮助/日志：纯文本对话框（日志对话框有【本次运行】/【已落盘】两段）。

## 8. 状态数据从哪来（改行为时先看这里）

| 数据 | 来源 |
| --- | --- |
| 实例列表 / 版本 / 端口 | `Manager.list_instances()`（读 `instances.json` + 扫描常见目录） |

| 日志内容 | 内存 `TextBuffer` + 落盘 `~/.config/dsh-manager/manager.log`（>512KB 轮转） |

## 9. 逐键验收清单（每条都要点一遍）

> 详细测试步骤见 `HANDOFF-PROMPT.md` §7；这里只列"必须成立的事实"。

1. 侧栏 `＋` 和 `＋ 新建实例` 打开同一个对话框
2. 点每个实例行：右侧 6 处信息全部跟着变（标题/徽标/路径/胶囊/PID·端口/状态）
3. 选中行样式 = 浅底 + 内边框 + 头像渐变（**不是**系统蓝/青）
4. 状态点颜色随运行状态变化（启停各看一次）
5. `打开窗口` 在"窗口已开/未开"两种情况下都对（置前 / 新开）
6. `⋯` 四项都在，卸载前有确认
7. `启动`/`停止` 互斥可用；点了状态与日志都变
8. `重载`/`重建` 都有效果（旧窗口时重载应给出提示）
9. 常用功能 4 格各自打开正确目标（日志/插件/更新/文件管理器）
10. Token 结果出现在日志区 + 剪贴板，且带 200/401 判定
11. 主题菜单 7 项齐全；每一项点了都立即换肤；当前项有勾选
12. 日夜按钮切换即时生效，文字变化
13. `ⓘ`、`使用帮助`、`查看完整日志` 三个对话框都能打开并关闭
14. 设置页：保存设置后有 toast，重开管理器仍保持
15. 更换主题循环正确；日志行数保存后生效
16. 复制诊断信息后剪贴板有内容
