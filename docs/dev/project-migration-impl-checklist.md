## 2. 评审发现（原型 vs 真实实现）

### 2.1 必须纠正（原型演示遗留）

| # | 现象 | 影响 | 实现规则 |
| --- | --- | --- | --- |
| A1 | 切换实例后，**项目列表不跟着过滤**（切换 dsh-new 后仍显示 dsh-test 的 3 个项目和 14.5 GB 汇总） | 数据串台 | 实例切换 = 重新查询该实例 home 的项目；列表、汇总、空态、徽标同步刷新 |
| A2 | 底部汇总（`3 个项目 · 8 个会话`）与实例选择器摘要（`2 个项目 · 5 个会话`）不一致 | 数字不可信 | 单一数据源：汇总行直接由当前列表计算 |
| A3 | 批量导出未勾选任何项目时，导出弹窗显示「0 个选定项目」 | 空操作 | 未选中 → 禁用「批量导出/批量备份」并提示「先选择项目」 |
| A4 | 行内操作（导出/备份/恢复）只在 hover 出现 | 键盘/触屏不可达 | hover 或 focus-within 时显示；`⋯` 常驻；操作按钮带 `aria-label` |

### 2.2 设计取舍（我认同，但要知道代价）

- **入口收进「管理器功能」**：实例概览保持原样，不新增每实例入口。项目靠卡内「数据范围」选择器切换。代价：从实例概览进不去项目，得多一步。
- **两张卡默认收起**：首屏干净，但用户首次使用要自己发现「项目备份 / 恢复」卡。
- **批量备份单位是实例**（「全部备份」），但备份与恢复仍是项目级（每个项目一个 `.dshproj`，历史一行代表一批）。

### 2.3 与你既定决策的吻合检查

| 决策 | 设计是否满足 |
| --- | --- |
| 换路径迁移 + 导入进度 | ✅ 向导第 4 步「改写设备路径」阶段 |
| 附件默认带 | ✅ 导出清单「引用附件」默认勾选 |
| 凭据不进包 | ✅「机器配置（不包含密钥）」单独勾选 |
| 管理器内定时备份 | ✅ 备份计划在卡内，无系统计划任务 |
| 保留份数用户可设 | ✅「每个项目保留份数 1 份（1 = 只保留最新一份）」+「最多保留 30 天」 |
| WebDAV 加密默认关 | ✅ 设计中无加密开关（保持默认关） |
| 冲突保留双份 | ✅ 恢复弹窗「冲突会话：保留双份 / 跳过」 |
| 交接摘要 + 设备戳 | ✅ 项目行「源：来自 V100 · 11-19」徽标 + 交接弹窗（设备、时间、摘要、完整记录路径） |
| 分实例展示项目 | ✅ 卡内实例选择器（代价见 2.2） |

## 3. 页面与组件清单（按实现顺序）

### S1 · 管理器功能页骨架

- 两张 `manager-feature-card`：
  - 摘要：44px 功能图标（渐变底）+ 标题 + 状态徽标 + 一行说明 + 右侧摘要（项目数 / 服务地址）+ 箭头；
  - 默认收起；点击摘要只切换自己；`aria-expanded` 同步；箭头旋转 180°。
- 面包屑追加第三段「项目备份 / 恢复」。

### S2 · 实例选择器（数据范围）

- 触发器：34px 头像 + 实例名 + 箭头；右侧同行显示状态点、端口、版本、`N 个项目 · N 个会话`、数据目录提示。
- 浮层：`card-solid`、圆角 15、宽约 310、`position: fixed` 跟随触发器；每行：34px 头像、名称、`DSH 版本 · N 个项目`、勾选图标；选中项主色浅底。
- 键盘：↑/↓、Home/End、Enter、Esc；关闭后焦点回触发器；点击外部关闭。
- 切换后刷新：项目列表、汇总、空态、目标实例文案、导出「来源实例」。

### S3 · 项目与迁移（tab 1）

**工具栏**：搜索框（占位「搜索项目…」）、状态筛选（全部项目 / 未备份 / 已备份 / 有更新）、排序（最近活动 / 名称 / 体积）、右侧 `N 个项目` + `[全部备份]` + `[+ 从备份新建]`。

**多选**：行首复选框；选中后出现选择工具条：`已选 N 个 · [批量备份] [批量导出] [清除]`。

**项目行**（61px 高左右，圆形浅底文件夹图标）：

| 字段 | 示例 | 状态 |
| --- | --- | --- |
| 标题 | 项目迁移设计 | 单行省略 |
| 徽标 | `● 已备份` / `● 未备份` / `● 有更新` / `● 备份中` | 颜色 + 文字 |
| 交接徽标 | `源：来自 V100 · 11-19` | 可点击打开交接弹窗 |
| 第二行 | `3 个会话 · 12.4 MB · 最近活动 10 分钟前（10:42）` | 相对时间 + 绝对时间 |
| 第三行 | `上次备份 11-19 10:42 · 本地 + NAS` / `从未备份 · 建议先导出当前状态` | 无备份时给建议 |
| 大项目提示 | `⚠ 体积较大，备份可能较慢`（>500 MB） | 琥珀色 |
| 行内进度 | 进度条 + 阶段文本 + 取消 | 行内任务进行时替换第三行 |
| 操作 | `导出` `备份` `恢复` `⋯` | hover/focus 显示前三，`⋯` 常驻 |

**状态页**：加载（骨架行）、空（「这个实例还没有项目」）、错误（「无法读取项目列表」+ 重试）、无搜索结果（「没有匹配的项目」+ 清除筛选）、部分成功黄条（`批量备份完成：2 个成功，1 个失败` + 展开详情 + 关闭）。

### S4 · 导出弹窗

- 头：下载图标 + 「导出项目」+ 说明「生成包含项目文件、会话和附件的迁移包。」
- 项目条：标题 + `来源实例：<实例> · 设备：<短码>`。
- 勾选清单（每项右侧体积）：会话历史（N 个会话·可继续对话）、项目文件（含 .dsh 隐藏配置、记忆库和文件历史）、引用附件（N 张图片）、机器配置（端口与路径等配置，不包含密钥）。
- 保存到（路径 + 浏览）、预计导出大小。
- 进度态：四阶段（打包会话历史 / 复制引用附件 / 写入项目文件 / 生成校验信息）+ 百分比 + 取消。
- 完成态：路径 + 「在文件夹中显示」+ 关闭。

### S5 · 恢复弹窗

- 头：「恢复项目」+「预览备份内容并选择写入方式，预检完成前不会修改项目。」
- 文件行：`<项目>.dshproj` + `SHA256 校验通过 · 备份格式 1.0` + 浏览。
- 信息表：项目 / 来源设备 / 备份时间 / 会话（含「其中 N 个与本机重名」）/ 附件。
- 处理方式单选：导入为新项目（保留当前项目，使用新项目名称）/ 合并到现有项目（合并会话与文件，按冲突规则处理）。
- 目标目录 + 浏览；冲突会话单选：保留双份（推荐）/ 跳过。
- 提示：`恢复会更改当前项目，开始前将自动导出当前状态作为备份。`（仅合并模式）
- 合并模式 → 二次确认弹窗：`确认合并并恢复项目？` + 当前状态已安全导出到 `<路径>` + 取消/继续恢复。
- 进度态：五阶段（解包与校验 / 改写路径 / 合并会话 / 复制附件 / 写注册表）+ 取消恢复。
- 完成态：`已导入，重启实例后可见` + 稍后 / 立即重启实例。

### S6 · 备份与恢复（tab 2）

**子标签**：本地备份 / WebDAV（WebDAV 带状态点）。

**备份计划**（本地）：
- 行 1：备份频率（每天 / 每周 / 每隔 N 小时）+ 执行时间（或间隔小时）+ 备份范围（全部项目 / 仅选定的项目…+ 选择按钮）。
- 行 2：保存到（路径 + 浏览）+ **每个项目保留份数**（默认 1，右侧注释「1 = 只保留最新一份」）。
- 行 3：□ 同时最多保留 N 天 + 包含内容（☑ 会话历史 ☑ 项目文件（含隐藏配置）☑ 引用附件）。
- 右下：`保存计划`；左侧 `下次执行：明天 03:00`。
- 右上开关：启用自动备份（关闭时计划区禁用/降透明）。
- 状态：加载骨架 / 无计划空态 / 保存失败内联错误条。

**备份历史**：每行 `时间 · 自动备份/手动 · N 个项目 · 体积 · 目标（本地目录/NAS）` + 状态（成功/失败）+ `恢复`（成功）/`日志`（失败）。空态：「还没有备份」+ `立即备份`。

**WebDAV**：
- 连接：地址输入 + 测试连接按钮 + 状态（`已连接 · 42 ms` / `正在测试` / 失败原因）；用户名/密码 + 「记住」（本机保存，不进包）；远程目录。
- 项目勾选列表：全选 + 每行项目名、体积、上次备份、状态；大项目提示；每行独立进度（% + 文案）、暂停/继续、重试；底部 `备份选中` + `从远端恢复…`（跳向导第 2 步）。
- 进度文案：`68% · 正在上传项目文件`、`32% · 已暂停`、`54% · 网络连接中断`。

### S7 · 任务日志（tab 3）

- 标题「任务日志」+ 清空；每条：时间、级别（成功/信息/错误）、内容、可展开详情。
- 来源：导出/恢复/备份/WebDAV 任务写入同一日志。

### S8 · 「从备份新建」五步向导（独立页面）

1. **选择来源**：本地目录（选文件夹）/ WebDAV（进入第 2 步直接列远端）。
2. **选择备份**：列表（项目、来源设备、时间、体积、会话数）+ 单选。
3. **预览与目录**：目标实例卡（头像、名称、运行状态、版本、端口、数据目录）+ `目标实例已确认` + 信息表（项目、来源设备、备份时间、内容、写入方式「仅新增，不覆盖」）+ 新项目名称（默认 `<原名>-恢复`）+ 目标目录 + 校验提示（「目标目录不存在同名项目，可以安全写入」）+ 安全边界说明。
4. **导入**：五阶段进度 + 取消。
5. **完成**：`项目已导入 ... 重启实例后可见` + 稍后 / 立即重启实例 + 返回备份 / 恢复。

顶部：面包屑 `管理器功能 / 项目备份 / 恢复 / <实例> / 从备份新建`；右上「返回备份 / 恢复」。

### S9 · 跨设备交接弹窗

- 标题「跨设备交接」+ 说明「这个项目在另一台设备上继续过，交接摘要会随项目一起迁移。」
- 字段：来源设备、交接时间、交接会话、摘要（多行）、完整记录（等宽路径）。
- 底部「知道了」。

### S10 · 全局组件

- **Toast**：底部居中，最小宽 230，圆角 13；成功/错误两色；2.6s；同一操作替换而非堆叠。
- **弹窗**：410px 宽（迁移弹窗可到 520–560），遮罩 28% + blur 8px；Esc/遮罩关闭；危险确认不可点遮罩确认。
- **状态徽标**：胶囊，点 + 文字；成功绿、未备份灰、有更新琥珀、失败红。
- **按钮**：Primary（渐变）/ Secondary / Compact / Text / Danger soft；禁用 45% 透明。
- **焦点环**：3px 主色 25% 透明，外偏移 2px。

## 4. 数据契约（管理器侧需要提供）

```ts
// 实例
Instance { id, label, dir, port, version, running, home, projectCount, sessionCount }

// 项目（ProjectCatalog 已实现雏形）
Project {
  id: string; path: string; title: string;
  sessions: number; sizeBytes: number; lastActivity: string;
  backupState: 'none' | 'backup' | 'outdated' | 'running';
  lastBackupAt?: string; backupLocation?: 'local' | 'webdav';
  hasHandoff: boolean; handoff?: { device, at, title, summary, recordPath };
  large: boolean;             // >500MB
}

// 备份记录（backups.json）
Backup { projectId, projectTitle, projectPath, kind: 'local'|'webdav', file,
         deviceShort, createdAt, sizeBytes, sha256, status: 'ok'|'failed' }

// 计划
BackupPlan { enabled, frequency: 'daily'|'weekly'|'hours', time, hours, scope: 'all'|'selected',
             projectIds[], directory, retentionCount, retentionDays, includeSessions,
             includeProjectFiles, includeAttachments }

// 任务
Task { id, type: 'export'|'import'|'backup'|'webdav'|'restore', projectId,
       stage, percent, status: 'running'|'paused'|'failed'|'done'|'cancelled', message }
```

| UI（两张卡/项目页/弹窗/向导） | ❌ | 按 §3 实现 |

## 8. 需要你确认的 2 个点

1. **实例概览是否真的要完全不动**？设计里没有从实例行直达项目的入口，必须先进「管理器功能」再选实例。可选：在实例行 `⋯` 菜单加「查看项目」跳转（不改布局）。
2. **「全部备份」的语义**：当前数据范围内的所有项目各打一个包（可能 3–5 GB）。是否要先弹确认（列出项目与总体积）再执行？我倾向要。
