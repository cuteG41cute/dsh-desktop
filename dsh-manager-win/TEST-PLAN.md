# dsh-manager Windows 2.0.17 · 全量验收清单（干净虚拟机）

目标：在一台**全新 Windows** 上，从零装一次管理器，逐项验证 2.0.x 的功能，避免“本机能跑、别人装上去就翻车”。

## 0. 前置

- [ ] 干净 Win11（沙盒 / Hyper-V 开发环境 / 全新装）
- [ ] 联网正常（能访问 github.com 与 nodejs.org）
- [ ] 记录初始状态：无 `%LOCALAPPDATA%\Programs\DSH Manager`、无 `%LOCALAPPDATA%\dsh-manager`

## 1. 安装与首启

- [ ] `install-win.ps1` 装到 `%LOCALAPPDATA%\Programs\DSH Manager`
- [ ] 桌面/开始菜单快捷方式存在
- [ ] 首启 1 秒内出窗口（记录到「扫描完成」的时间）
- [ ] 四角是**圆角**，外面没有方形灰角
- [ ] 最小化 → 还原，四角仍是圆角
- [ ] 最大化 → 还原，四角仍是圆角
- [ ] 切换主题（毛玻璃 → 液态玻璃 → 深色），窗口与子窗口一起变

## 2. 新建实例（源码方式）

- [ ] 打开「新建实例」：默认目录是 `…\instances\dsh-new`（若被占用则自动 `-2`）
- [ ] 把「实例名称」改成 `test-new` → 安装目录自动跟随为 `…\instances\test-new`
- [ ] 手动把目录改成**已存在的实例目录** → 点创建 → 被拒绝且给提示
- [ ] 手动把目录改成**已有非空目录** → 点创建 → 被拒绝且给提示
- [ ] 端口填一个已被占用的端口 → 被拒绝且给提示
- [ ] 正常创建：clone → 装 pnpm → pnpm install → build 全流程走完（首次约 10 分钟）
- [ ] 创建过程中日志卡片出现并滚动；创建成功后日志保留
- [ ] 若断网/超时：Node 下载会**自动重试一次**，失败提示里带具体原因

## 3. 实例管理

- [ ] 新实例出现在侧栏，标题是**目录名**（不是包名）
- [ ] 数据目录是 `<实例>\dsh-home`（全新空目录），没有继承全局工作区/插件
- [ ] 「启动 / 停止」按钮随状态切换；点停止后管理器**不退出**、状态变灰
- [ ] 停止后再启动，服务能起来
- [ ] 「删除实例」：先停服务 → 删目录 → 移出列表
- [ ] 刷新按钮：转满一圈停下，状态行「正在刷新中…」→「已刷新（N 个）」

## 4. 仪表盘

- [ ] 状态徽标（标题胶囊 / 快捷控制）与实际运行状态一致（未运行=灰）
- [ ] 常用功能 4/2/1 列，每行填满、右边缘贴齐
- [ ] 最近日志只显示 15 条，可「查看完整日志 →」
- [ ] 「窗口功能」窗口：两个开关可切换，切换后会话窗口自动重载
- [ ] 「查看 Token」：地址 / token / cookie / 校验结果齐全，可复制、可「重新获取 token」

## 5. 内置会话窗口

- [ ] 点「打开窗口」能打开并加载出界面（不是白屏、不是 401）
- [ ] 图片预览：`Ctrl + 滚轮` 放大/缩小，右上角出现缩放工具栏
- [ ] 图片放大后**按住左键拖动**能平移（开关「放大后拖动平移」= 开）
- [ ] 关掉该开关 → 窗口重载 → 再拖不动；重新打开 → 又能拖
- [ ] 右栏文件树：拖一个**文件**到桌面 → 落地保存
- [ ] 拖一个**目录**到桌面 → 整目录复制
- [ ] 拖到输入框 → 变成路径文本
- [ ] 关掉「文件/目录拖出」→ 重载 → 拖不出；再打开 → 恢复

## 6. 检查更新

- [ ] 点击后窗口**立刻出现**，顶部转圈（弧在转）
- [ ] 列表加载完成后，两个下拉可用，第一项是「保持当前（当前版本）」
- [ ] 只显示一处「当前」，不会每行都标当前
- [ ] 选一个更低版本 → 应用 → 版本真的降下去（状态行提示切换结果）
- [ ] 系统安装（npx/pi-node）实例：应用按钮禁用并提示

## 7. 退出与托盘

- [ ] 点 X 收进托盘；再双击快捷方式能把窗口叫回来（不是“没反应”）
- [ ] 托盘图标是黑鲸鱼（不是系统默认程序图标）
- [ ] 管理器退出后，实例服务仍在运行（解耦验证）
- [ ] 管理器崩溃/强杀后，实例仍在线

## 8. 记录

把每一步的实际结果与截图存到 `vm-shots\vm-test-*.png`，失败项写明：现象、`ui.log` / `web.log` 里的相关行。
