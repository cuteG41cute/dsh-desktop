# DeepSeek Harness 管理器 · Windows 版 v1.0.2

只改会话窗口连哪儿，功能与 1.0.1 相同。

## 这一版改了什么

- **电脑端窗口改成直连实例端口**（`127.0.0.1:<port>`）：
  之前照移植过来的 Linux 启动器逻辑，3080 的实例会先探测手机端桥（8099）并通过桥打开
  —— 目的是让桌面窗口里也有「设置 → 手机端」面板。但桌面窗口本来就在同一台机器上，
  绕一层反向代理只是多一跳、还多一个「桥没在跑就退化」的分支。
  现在窗口永远直连，标题栏也不再显示「· 手机端桥」。
- **桥只保留给手机/平板**：`dsh-mobile-bridge` 还是监听局域网 8099、反代到本机实例；
  启动服务时仍然会给每个局域网 IP 补 `--trusted-host <ip>:8099`，手机侧 `/api` 才不会被
  来源栅栏拦掉。
- 顺带删掉 `DSH_MANAGER_DIRECT` 环境变量和整个桥探测代码（不再需要绕行开关）。

## 代价（说清楚）

桌面窗口不再经过桥，所以**桌面窗口的设置里没有「手机端」那一段**（那段是桥注入的客户端插件）。
手机上照旧有：手机浏览器打开 `http://<本机IP>:8099/` 就能看到面板。

## 下载

- `DshManager.exe`（单文件自包含，63 MB，内置 .NET 运行时，不需要装 .NET）
- `install-win.ps1` / `uninstall-win.ps1`

## 安装 / 升级

```powershell
powershell -ExecutionPolicy Bypass -File install-win.ps1
```

覆盖安装即可（先托盘 → 退出正在运行的管理器）。

## 主要功能

- 实例管理：扫 npx 缓存 / pi-node / 全局 npm / `%DSH_HOME%\profiles` / PATH / 管理器新建的；
  按端口反查在跑的服务；启动 / 停止 / 重启 / 检查更新 / 修复 / 卸载
- 内置会话窗口（WebView2）：直连实例端口，自动签发认证 cookie，同端口单实例，服务没跑会先拉起来
- 主题联动（`prefers-color-scheme`）、插件管理、新建实例
- 7 套主题 × 昼/夜、黑色鲸鱼图标、单实例 + 托盘、720×450 响应式布局
