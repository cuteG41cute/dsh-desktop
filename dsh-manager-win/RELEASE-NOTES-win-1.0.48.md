# dsh-manager Windows 1.0.48

自 1.0.4 以来的完整变更（1.0.5 → 1.0.48）。

## 启动与性能

- **启动慢修复**：扫描从 **6.2 秒 → 0.34 秒**。原因是 `AttachRunning` 对 3080..3099 共 20 个端口逐个 TCP 连接、每次最多等 300ms；改成一次 `netstat` 拿整张「端口 → PID」表（缓存 2 秒）。
- `node` 命令行的 PowerShell 查询移出热路径（先返回上次结果、后台刷新），首次加载改为后台线程扫描，窗口先画出来再回填。
- **拖动缩放优化**：关掉分层窗口（`AllowsTransparency=False`，改为 DWM/Region 画圆角），拖动期间不跑重排、临时摘掉 8 个 `DropShadowEffect`、图片降采样、文字临时灰度；再从「实时排版」改为「矢量缩放」（Canvas + RenderTransform，四角锁宽高比，按拖拽方向预置缩放算式），帧时间 60–76ms → 14–15ms。

## 实例与服务

- 新建实例改为**从官方仓库克隆**（`git clone` → 实例内装 pnpm → `pnpm install` → `pnpm run build`），可选 GitHub tag 作为「仓库版本」；便携 Node、pnpm、store、仓库、`dsh-home` 全部落在实例目录内。
- 每个实例使用**独立的 `dsh-home`**（新实例为全新空目录，不再继承其它实例的工作区/插件）。
- **实例与管理器解耦**：服务通过生成的 `run.cmd` 把输出重定向到日志文件，不再用管道，管理器退出/崩溃不会带走实例（顺带修掉日志乱码：UTF-8 读写）。
- 未运行时按钮显示「**启动**」，运行中显示「停止」；仪表盘底部新增「**删除实例**」（停服务 → 删目录 → 移出登记表）。
- 新建实例校验**端口占用**（已在用 / 被其它程序监听都拒绝）。
- 侧栏图标从「+」改为「**刷新**」：点击后按钮转满一圈、状态行「实例列表正在刷新中…」→「已刷新（N 个）」。

## 界面

- **四角圆角**：改为 `SetWindowRgn` 按设计半径裁剪窗口（26 DIP），启动时即生效，不再露出方形灰角。
- **常用功能**卡片改用 `UniformGrid`：只有 **4 / 2 / 1 列**三档，每行必然铺满、右边缘贴齐。
- 「最近日志」只显示**最新 15 条**（完整日志走「查看完整日志 →」）。
- 状态徽标（标题胶囊、快捷控制「服务正常」）全部跟随真实运行状态，未运行=灰点。
- 托盘图标改为 exe 内嵌图标（黑鲸鱼），修掉「句柄失效导致进程静默崩溃」；单实例启动时会把藏在托盘里的旧窗口捞出来。
- UI 线程异常不再静默退出（只记 `ui.log`）；启动/停止/重启不弹窗，只写状态行。

## 检查更新 / Token

- 「检查更新」改为独立的**版本选择窗口**：窗口先弹出、列表异步加载（顶部 DSH 风格转圈），可选 dsh 与 Node 两个版本（第一项「保持当前（x.y.z）」），支持**升级与降级**；底部「检查更新」可重拉。
- 修复版本检测「把 0.0.1 当最新」：`npm view versions` 是**旧→新**数组，之前取了第一个；现在从末尾取并优先非 alpha。
- **查看 Token** 改为主题窗口（随主窗口主题变化）：显示访问地址、本次启动 token、带 token 地址、认证 cookie、**当场校验结果（200/401）**；底部「重新获取 token」「复制带 token 地址」「复制全部」「关闭」。

## 安装

下载 `DshManager.exe` 覆盖到 `%LOCALAPPDATA%\Programs\DSH Manager\` 即可（或用 `install-win.ps1`）。
