# dsh-manager 1.4.5 — 按设计规范逐像素复刻

这一版把管理器界面**按 `DESIGN_SPEC.md`（Kimi 出的设计规范）逐条对齐**，并建立了可复跑的像素/几何/配色门禁。

## 主要变化

### 1. 布局按规范基建
- 侧栏 248 / 顶栏 66 / 内容内边距 25·30·15 / 卡片 1.65:1（右列最小 330）/ 常用功能四列 11px / 设置页 1.5:1（右列最小 320）间距 17。
- 实例卡与控制卡 **205px** 高、内边距 18×20；实例行 61px、圆角 13、行距 5；快捷卡 82px；日志栏 45px + 内边距 7·18·9；设置卡 21px、信息行 40px。
- 修正了 GTK 的两处盒模型陷阱：**`min-height` 只算内容盒**（设计稿 height 含 padding+border）、**CSS `margin` 与 `set_margin_*()` 会叠加**。

### 2. 响应式两档（§2.5）
- ≤1280px：侧栏 220、内容/顶栏内边距 22、卡片内边距 16、快捷卡 70 高。
- ≤850px 高：标题区收紧、隐藏页面说明与页脚、卡片 min-height 190。
- 常用功能按用户要求**始终四列**（不采用规范里的窄屏两列）。

### 3. 七主题配色与材质
- 29 个 CSS 变量 × 7 主题 × 日/夜 = **266 个色值与设计稿完全一致**（有门禁逐项比对）。
- 七套主题的 app/card 圆角全对（26/32/20/14/24/28/24、20/25/14/12/18/20/18）。
- crystal 主题补上了设计稿的专属皮肤（`linear-gradient(135deg, rgba(255,255,255,.62), card)` + 内嵌高光）。

### 4. 图标与组件细节
- 从设计稿抽出 **25 枚 SVG 图标**，运行时按主题色着色（切主题自动重上色），不再用 `＋ ↗ ⓘ` 这类字符凑。
- 状态徽标 = 5px 圆点 + 文字（圆点随运行/停止/需修复变色）；运行指示 5px 圆点 + 文案。
- 药丸尺寸按设计稿修正（实测 Gtk.EventBox 的 CSS `padding` 不参与尺寸计算，改用内部 label 的 margin）。
- 侧栏链接去掉 GTK 默认按钮边框；日夜开关做成"太阳 + 月亮 + 滑块"胶囊；顶栏顺序 = 触发器 → 开关 → 分隔线 → 信息。
- 焦点环（3px 主色 25%，用 box-shadow 实现以免影响布局）、禁用态（透明度 48%）按 §7.1 / §8.3 落地。

## 安装

```bash
sudo dpkg -i dsh-manager_1.4.5_all.deb
dsh-manager --version   # 1.4.5
```

依赖：GTK3、python3-gi；「打开窗口」需要 gir1.2-webkit2-4.1 或 4.0。

## 已知差异（引擎上限，不是缺陷）

- **字体栅格化**：设计稿由 Chromium 渲染，GTK 用 Pango/FreeType，字形边缘必然不同；设计稿字体栈是 Windows 专有的 Segoe UI / 微软雅黑。
- **字重**：GTK3 的 `font-weight` 基本只有 normal/bold，设计稿的 600/650 会被渲染成 Bold（虚拟机上的 Noto Sans 没有 Semibold）。
- **`backdrop-filter`**：GTK3 没有背景模糊，crystal 主题的玻璃质感只能近似。

## 复刻质量（可复跑的门禁）

| 维度 | 判据 | 结果 |
| --- | --- | --- |
| 配色 | 266 个色值逐项比对 | 全部一致 |
| 几何 | 27 个元素 x/y/w/h，容差 ±2px | 结构性元素全部 ≤2px |
| 像素 | 7 主题 × 日/夜 × 2 页 = 28 组 MAE | 平均 5.55，最好 3.6 |
