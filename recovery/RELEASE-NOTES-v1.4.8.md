# dsh-manager 1.4.8 — 无边框窗口与统一子窗口

这一版把窗口本身和所有对话框都做成了和主界面同一套外观，并跟随主题切换。

## 无边框窗口（1.4.6 / 1.4.7）

- **去掉系统标题栏**：走 CSD（`set_titlebar` 一个零高度自绘控件）。在 KDE Wayland 上，
  只调 `set_decorated(False)` 会触发 KWin 画兜底标题栏与右下角的图标徽标，必须走 CSD 才干净。
- **自绘窗口按钮**：右上角 最小化 / 最大化-还原 / 关闭（32×32 热区，图标与其余 25 枚同规格：
  24 viewBox、1.7 线宽、圆角端点）。关闭键悬停变危险色。
- **顶栏空白处可拖动窗口，双击切换最大化**；最大化时窗口圆角与外壳圆角一起归零。
- **真正的圆角窗口**：窗口开 RGBA + `set_app_paintable`，在 `draw` 里清透明、按主题 `app-radius`
  裁切、再自己铺主题背景图（`app_paintable` 之后 GTK 不再替你填背景）。
- **修掉"双层圆角"**：GTK 的 CSD `decoration` 节点会在窗口内缘再画一圈阴影/边框，
  已清零；修前取样能看到 6px 灰蓝过渡带，修后窗口边缘直接是界面像素。
- **退路**：`DSH_MANAGER_SYSTEM_TITLEBAR=1` 可回到系统标题栏。

## 子窗口统一风格（1.4.8）

所有对话框都走同一个 `_style_dialog()`：

- 自绘 CSD 标题栏（主标题 + 副标题，关闭按钮在右侧，符合 KDE 习惯）；
- 背景用主题 `card-solid`，自绘圆角 18px；
- 表格/列表的**选中色改成主题强调色**（原来是系统蓝底白字），列头、悬停、说明文字都用主题令牌；
- 动作区按钮统一成主界面按钮风格（主动作 `btn-primary`，其余 `btn-secondary`）；
- 内容区不再重复标题。

覆盖的对话框：插件管理、完整日志、新建实例、更新实例（导入/选目录两个文件选择框共用按钮样式）。

## 安装

```bash
sudo dpkg -i dsh-manager_1.4.8_all.deb
dsh-manager --version   # 1.4.8
```

依赖：GTK3、python3-gi；「打开窗口」需要 gir1.2-webkit2-4.1 或 4.0。

## 已知差异

- **对话框圆角偏方**：已走自绘圆角，但四角仍带 GTK 的 CSD 边；要完全干净需要把主窗口那套整窗裁切搬过来。
- **动作区按钮偏矮**：受系统 action-area 制约，已加 `min-height: 30`。
- **未接入的窗口**：关于/帮助、崩溃对话框仍是独立 `Gtk.Window`，未套用主题。
- 字体栅格化与 `backdrop-filter` 的限制与 1.4.5 一致（GTK3 能力边界）。
- 当前主题下 Noto Sans 只有 Regular/Bold，设计稿的 600/650 会渲染成 Bold。
