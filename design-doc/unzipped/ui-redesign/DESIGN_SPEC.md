# DeepSeek Harness 管理器 · 视觉与交互设计规范

版本：1.0  
适用范围：实例概览、管理器设置、主题系统及其全部通用组件  
实现基准：`index.html`、`styles.css`、`app.js`  
参考画布：1440 × 900 px，桌面端优先

---

## 1. 设计目标

### 1.1 核心原则

1. **状态先于装饰**：实例是否运行、当前选中项、操作结果必须首先被看见。
2. **高频操作前置**：打开窗口、服务启停、页面重载位于第一屏主要区域。
3. **危险操作隔离**：卸载不与启动、重载等日常操作并列；正式程序中必须二次确认。
4. **同构不同肤**：七套主题共享布局、字号层级、组件结构与交互，仅替换设计变量和背景图形。
5. **日间与夜间分别配色**：夜间模式不是简单反色；降低纯白面积，保留品牌色与状态色辨识度。
6. **透明材质有边界**：玻璃主题同时使用背景模糊、半透明填充和细分隔线，不能只依赖模糊区分层级。

### 1.2 信息架构

- **一级导航**：实例概览、管理器设置、使用帮助。
- **实例导航**：实例列表、新建实例、运行状态。
- **实例概览**：标题与状态 → 实例信息与服务控制 → 常用功能 → 最近日志。
- **管理器设置**：管理器信息、维护与诊断、外观与日志。
- **全局操作**：主题选择、日夜切换、通知。

### 2.3 内容区网格

| 区域 | 网格规则 | 间距 |
|---|---|---:|
| 实例概览双卡 | `1.65fr : 1fr`，右列最小 330px | 16px |
| 常用功能 | 四列等宽 | 11px |
| 设置页 | `1.5fr : 1fr`，右列最小 320px | 17px |
| 实例指标 | 三列等宽 | 分隔线 + 15px 左内边距 |
| 页面标题与操作 | 两端对齐 | 最小间距 20px |

### 2.4 间距系统

以 **4px** 为基础单位；允许 1–2px 用于图标光学校正和细标签。

| 名称 | 数值 | 典型用途 |
|---|---:|---|
| `space-1` | 4px | 主副标题、图标细节 |
| `space-2` | 8px | 按钮图文、标题与操作 |
| `space-3` | 12px | 卡片内部小组件、输入框水平内边距 |
| `space-4` | 16px | 卡片网格间距 |
| `space-5` | 20px | 卡片内边距、区块间距 |
| `space-6` | 24px | 页面外边距、侧栏分区 |
| `space-8` | 30/32px | 主内容水平内边距、弹窗内边距 |

现有原型中的 5、6、7、9、10、11、13、17、18、21、22、25px 为针对紧凑桌面界面的局部微调，不应继续无规则增加新值。

### 2.5 响应式规则

- **宽度 ≤1280px**：页面外边距改为 14px；侧栏 220px；内容与顶栏水平内边距 22px；常用功能改为两列；快捷卡高度 70px；概览双卡比例改为 `1.35fr : 1fr`。
- **高度 ≤850px**：隐藏页面说明和页脚；减小标题区、卡片和侧栏的垂直间距；实例卡与控制卡最小高度 190px。
- **内容溢出**：仅主内容区纵向滚动；左侧导航和顶栏保持固定。
- **触控或移动端**：当前版本未设计手机布局，不应简单压缩桌面界面。

## 3. 字体与排版

### 3.1 字体族

```css
--font: "Segoe UI", "Microsoft YaHei UI", "Microsoft YaHei", sans-serif;
```

- **中文**：微软雅黑 UI / 微软雅黑。
- **英文与数字**：优先 Segoe UI。
- **路径、版本、PID、日志时间**：`Consolas, "Microsoft YaHei", monospace`。
- **跨平台建议**：Linux 使用 `Inter, "Noto Sans CJK SC", "Source Han Sans SC", sans-serif`；等宽使用 `JetBrains Mono, monospace`。更换字体后必须重新检查文本宽度。

### 3.2 当前原型字号层级

| 样式 | 字号 / 行高 | 字重 | 字距 | 用途 |
|---|---|---:|---:|---|
| Display | 25 / 31px | 680 | -0.035em | 实例名称、设置页标题 |
| Brand | 13 / 默认 | 700 | -0.15px | DeepSeek Harness 品牌名 |
| Card title | 13 / 默认 | 650 | 0 | 实例名称、设置卡标题 |
| Section title | 12 / 默认 | 650 | 0 | 常用功能、最近日志 |
| Body strong | 11–11.5 / 默认 | 600 | 0 | 按钮、导航、实例名称 |
| Body | 10–11 / 1.5–1.7 | 400–500 | 0 | 说明、表单、列表 |
| Caption | 8.5–10 / 1.4–1.6 | 400–600 | 0 | 版本、指标标签、辅助信息 |
| Eyebrow | 8 / 默认 | 750 | 0.16em | 英文栏目标识 |
| Code | 8.5–9 / 1.5 | 400–600 | 0 | 路径、日志与运行参数 |
| Logo | 19 / 38px | 750 | 0 | 品牌字母 D |

### 3.3 排版规则

- 标题采用左对齐，避免大段居中。
- 实例名、路径和卡片辅助说明统一单行省略；完整值应通过工具提示或详情页查看。
- 数字指标使用 600–650 字重，版本标签中的数字比标签本身更突出。
- 中文正文不使用全大写；英文 eyebrow 才使用大写与宽字距。
- 日志正文保留等宽字体，但日志级别标签使用普通界面字体。
- **可读性建议**：原型中的 7.5–10px 仅用于次要标签。正式 GTK 应用建议正文不低于 12px、辅助文字不低于 11px，并允许用户调整界面缩放。

## 4. 颜色系统

### 4.1 语义变量

| 变量 | 含义 | 禁止用途 |
|---|---|---|
| `--bg / --bg2` | 背景渐变两端 | 不作为正文文字色 |
| `--app` | 应用主容器材质 | 不替代弹窗实色背景 |
| `--sidebar` | 侧栏材质 | 不表示选中态 |
| `--topbar` | 顶栏材质 | 不作为警示色 |
| `--card` | 普通卡片材质 | 不用于菜单等浮层 |
| `--card-solid` | 菜单、弹窗、提示条实色/近实色背景 | 不依赖透明背景显示浮层 |
| `--text` | 主文字与主要图标 | 不用于大面积填充 |
| `--muted` | 次级文字 | 不用于极淡禁用文字 |
| `--subtle` | 三级说明、时间、占位信息 | 不承载关键操作 |
| `--border` | 外轮廓与玻璃高光边 | 不等于内部分隔线 |
| `--inner-border` | 内部线条、输入框边框 | 不作为高亮轮廓 |
| `--accent / --accent2` | 主色与渐变辅色 | 不用于错误状态 |
| `--accent-soft` | 主色浅底、选中背景 | 不单独表示成功 |
| `--on-accent` | 主色按钮上的文字 | 必须保证对比度 |
| `--success` | 运行、成功、正常 | 不用于普通品牌装饰 |
| `--danger` | 停止、卸载、错误 | 不用于普通主按钮 |
| `--hover` | 悬停和部分选中背景 | 不作为唯一焦点提示 |

状态不能只靠颜色表达，必须同时保留文字、圆点或图标。

## 5. 圆角、材质、阴影与背景图形

### 5.1 主题材质参数

| 主题 | App 圆角 | 卡片圆角 | 背景模糊 | 材质特征 |
|---|---:|---:|---:|---|

| 液态玻璃 | 32px | 25px | 36px | 大圆角、内侧高光、流动蓝紫光斑 |
| 水晶 | 20px | 14px | 22px | 清晰高光边、切面多边形、斜向渐变 |
| 扁平化 | 14px | 12px | 0 | 实色、1px 边线、无卡片阴影 |
| 雪山 | 24px | 18px | 24px | 冰蓝材质、山脊与雪顶剪影 |
| 晨光 | 28px | 20px | 24px | 暖白材质、桃橙光晕、柔和日出 |
| 静海 | 24px | 18px | 25px | 青绿材质、双层海浪、低饱和阴影 |

### 5.2 阴影层级

- **应用窗口**：大范围 24–30px 垂直偏移、70–80px 模糊；透明度 13–18%，夜间提高到约 35%。
- **普通卡片**：`0 8px 24px`，透明度约 4–8%。扁平主题为 `none`。
- **主按钮**：`0 7px 16px rgba(accent,.20)`；悬停改为 `0 9px 22px rgba(accent,.28)`。
- **浮层**：`0 18px 45px rgba(20,20,45,.18)`。
- **弹窗**：`0 30px 80px rgba(20,20,45,.25)`。
- **玻璃高光**：液态玻璃增加 `inset 0 1px 0 rgba(255,255,255,.45–.7)`；水晶增加 2px 内侧斜向高光。

### 5.3 背景图形约束

- 背景图形只用于氛围，透明度低于主要内容，不进入文本阅读层。
- 图形置于固定场景层，`pointer-events: none`，不能拦截操作。
- 雪山：底部山脊约占画面高度 58%，雪顶为独立浅色路径。
- 静海：底部双层波浪约占画面高度 48%，两层透明度略有差异。
- 晨光：400 × 400px 径向日光，位于右上，中心不完全露出。
- 水晶：280 × 400px 切面多边形，旋转、斜切并裁切，不使用照片。
- 毛玻璃/液态玻璃：540–620px 径向光斑，允许大面积超出窗口。

- 统一 `24 × 24` viewBox。
- 线宽 1.7px，圆角线帽、圆角连接。
- 默认 `fill: none; stroke: currentColor`，颜色继承文字或组件状态。
- 标准尺寸 20px；按钮 16px；导航 17px；紧凑按钮 13px；箭头 12px。

| Compact | 高 31px，水平内边距 10px | 圆角 9px、13px 图标 | 卡片内嵌控制 |
| Text | 内容高度 | 无底无边，主色 | 查看完整日志、换主题 |
| Dashed | 高 38px | 1px 虚线边框 | 新建实例入口 |

通用规则：

- 标准圆角 11px，图标与文字间距 7px，标准图标 16px。
- 悬停：Primary 上移 1px并加强阴影；Secondary 使用 `hover` 背景；Text 显示下划线。
- 按下：下移 1px；快捷卡悬停则上移 2px。
- 焦点：3px 主色焦点环，不能只改变背景。
- 禁用态（开发补全）：透明度 45–55%，取消阴影和位移，使用 `cursor: not-allowed`。
- 加载态（开发补全）：保留按钮宽度，文字改为进度说明并显示旋转指示，防止重复提交。

### 7.2 实例导航 Instance item

- 尺寸：宽 100%，高 61px；内边距 8 × 10px；圆角 13px。
- 内部：34px 头像 + 10px 间距 + 实例名/版本 + 6px 状态点。
- 默认：透明背景；悬停：`hover`；选中：`hover` 背景、内边框和轻阴影。
- 运行：绿色状态点；停止：灰色状态点；不能只靠头像颜色表示状态。
- 实例名过长时单行省略，版本始终保留在第二行。
- 实例列表垂直间距 5px。

### 7.3 侧栏导航 Side link

- 高 40px，水平内边距 11px，圆角 10px。
- 图标 17px，图文间距 10px。
- 选中项：主色文字、600 字重、`hover` 背景。
- 外部帮助在末尾增加 13px 外链图标，透明度 55%。

### 7.4 运行环境卡 Runtime

- 外边距：上 17px、左右 4px；内边距 13 × 10px；圆角 12px。
- 左侧 28px Py 图标，中间正常状态与环境版本，右侧 5px 状态点。
- 该卡用于整体状态，不应放置多个操作按钮。

### 7.5 顶栏与面包屑

- 顶栏高 66px，水平内边距 30px，下边 1px 分隔线。
- 面包屑三段：父级 / 分隔符 / 当前页；字号 11px，段间距 9px。
- 全局操作区间距 10px，通知与日夜开关之间保留 1 × 20px 分隔线。

### 7.6 主题选择器

- 触发器高 34px，圆角 10px，包含 14px 主题色样、主题名和 14px 下箭头。
- 菜单宽 230px，上偏移 43px，内边距 7px，圆角 15px，使用 `card-solid`。
- 每行高 38px，包含 12px 色样、名称、简短描述；当前项右侧显示对勾。
- 菜单层级 `z-index: 20`；点击外部或 Escape 关闭。

### 7.7 日夜开关

- 外框 57 × 30px，胶囊圆角 16px。
- 滑块 22 × 22px，左/上偏移 3px。
- 日夜间滑块位移 27px，过渡 250ms。
- 太阳/月亮图标均为 14px；非当前模式降低透明度。
- 开关必须同步更新 `aria-label`。

### 7.8 状态标记

- 运行徽标：高由内容决定，垂直内边距 4px、水平 9px；胶囊圆角 12px。
- 组成：5px 圆点 + 5px 间距 + “运行中/已停止”。
- 运行使用成功色浅底；停止使用灰色和 `accent-soft`。
- 普通状态点 7px，带 3px、10% 成功色外环；紧凑场景可缩为 4–6px并取消外环。
- 日志级别：最小宽 29px，圆角 4px，分为成功、信息、系统三类。

### 7.9 卡片与实例信息

- 普通卡片：1px 外边框、主题圆角、卡片材质、卡片阴影；玻璃主题启用背景模糊。
- 实例卡/控制卡：最小高 205px，内边距 18 × 20px。
- 大实例头像：48 × 48px，圆角 14px，内有 1px 高光边。
- 版本胶囊：3 × 7px 内边距，6px 圆角，两项间距 6px。
- 指标区：顶部 1px 分隔线；上内边距 13px；三列等宽。
- 路径最长约 430px，超出省略；用户需要完整路径时提供复制或工具提示。

### 7.10 快捷控制卡

- 两组操作：服务、窗口。
- 每组左侧为名称与说明，右侧为两个 Compact 按钮。
- 两组之间：1px 分隔线，上外边距 17px。
- 服务运行时使用“重启 + 停止”；停止后主动作变为“启动”。
- 不在此卡放入卸载，避免与日常控制混淆。

### 7.11 快捷功能卡 Quick action

- 四列布局，高 82px，内边距 13px，圆角 15px。
- 左侧 34 × 34px 图标容器，圆角 10px，图标 17px。
- 右侧主标题与一行说明；说明超长省略。
- 悬停：上移 2px、主色边框、轻阴影；右上箭头从左侧 3px 淡入。
- 整张卡片都是点击区域，不要求用户精确点击箭头。

### 7.12 日志卡

- 标题栏高 45px，水平内边距 18px。
- 标题包含 15px 终端图标、栏目名和数量胶囊。
- 日志区内边距：上 7、左右 18、下 9px。
- 每行最小高 27px，字段顺序为时间 → 级别 → 内容，间距 11px。
- 时间使用三级文字色；正文使用主文字色；PID、端口等参数使用次级色。
- 完整日志应支持复制、滚动、清空和级别筛选；当前原型只演示入口。

### 7.13 表单与设置卡

- 设置卡内边距 21px；标题区下内边距 17px，并带底部分隔线。
- 信息行最小高 40px；左侧字段名、右侧值；路径值右对齐。
- 输入框高 38px，水平内边距 12px，圆角 10px。
- 字段标签下间距 8px；辅助说明上间距 7px，行高 1.6。
- 数字输入右侧单位“行”为辅助信息，不应成为可点击按钮。
- 外观预览卡包含 30px 色样、主题名、模式名和“更换主题”文字按钮。
- 设置提示条使用 `accent-soft` 背景、14px 信息图标和简短说明。

### 7.14 下拉菜单与更多操作

- 更多菜单宽 215px，上偏移 46px，内边距 6px，圆角 14px。
- 菜单项高 37px，圆角 8px，图标 15px。
- 普通项与危险项之间使用 1px 分隔线，外边距 5px。
- 浮层必须使用近实色背景，避免复杂背景穿透影响阅读。
- 正式实现需补充键盘上下键、Home/End、焦点返回和焦点约束。

### 7.15 弹窗 Modal

- 宽度 410px，内边距 30px，圆角 22px。
- 遮罩：深色 28% + 8px 背景模糊。
- 关闭按钮位于右上 15px；内容上图标容器 42 × 42px。
- 标题 19px；说明 10px、1.7 行高；底部按钮右对齐。
- Escape 与点击遮罩关闭；正式危险操作弹窗不应允许点击遮罩直接确认。

### 7.16 提示条 Toast

- 最小宽 230px，底部 35px，水平居中。
- 内边距 12 × 17px，圆角 13px，近实色背景。
- 左侧 24px 成功图标，右侧为结果文本。
- 初始下移 20px且透明；显示时 250ms 回到原位。
- 默认展示 2600ms；相同操作应更新当前提示而不是无限堆叠。
- 错误提示正式开发时使用危险色和错误图标，并延长停留或提供关闭按钮。

## 8. 交互与动效

### 8.1 时长与曲线

| 动效 | 时长 |
|---|---:|
| 按钮位移、背景、阴影 | 180ms |
| 导航、卡片、图标变化 | 200ms |
| 日夜滑块 | 250ms |
| Toast 入场/退场 | 250ms |
| 页面背景与文字换色 | 350ms |

建议统一使用 `cubic-bezier(.2,.8,.2,1)`；当前 CSS 使用默认 ease，正式实现可集中为主题变量。禁止添加强调装饰的大幅弹跳、持续漂浮或自动播放动画。

### 8.2 状态反馈

- 所有点击必须产生页面变化、弹窗、菜单或可感知提示之一。
- 启停服务后同步更新：实例状态点、标题徽标、PID、指标、控制卡状态、按钮文字。
- 主题切换立即预览并保存到本地；无需重启。
- 新建实例后立即加入侧栏、更新计数并选中新实例。
- 操作未完成前不能显示“成功”；正式后端接入时应区分执行中、成功和失败。
- 原型中的操作提示属于界面演示，不代表真实服务已经执行。

### 8.3 键盘规则

- `Tab / Shift+Tab`：按视觉顺序移动焦点。
- `Enter / Space`：激活按钮和卡片。
- `Escape`：关闭菜单、弹窗。
- 菜单打开时焦点进入菜单；关闭后回到触发按钮。
- 弹窗打开时焦点约束在弹窗内；关闭后回到原操作入口。
- 焦点环不可被全局 `outline: none` 移除。

## 9. 七套主题的设计语义

| 主题 | 关键词 | 最适合 | 应避免 |
|---|---|---|---|
| 毛玻璃 | 柔和、轻量、现代 | 默认通用界面 | 过多彩色光斑影响阅读 |
| 液态玻璃 | 流动、高光、圆润 | 展示型、个性化界面 | 高饱和渐变铺满正文 |
| 水晶 | 清透、切面、精致 | 科技感与结构感 | 过强折射和尖锐边框 |
| 扁平化 | 清晰、直接、高效 | 长时间运维与低性能设备 | 无边界导致层级不清 |
| 雪山 | 冷静、纯净、开阔 | 偏理性、低干扰场景 | 雪景对比过高 |
| 晨光 | 温暖、轻盈、亲和 | 日间与个人工作空间 | 暖色过多导致警示色混淆 |
| 静海 | 沉静、稳定、深邃 | 夜间与专注场景 | 青绿色同时承担所有状态 |

主题只改变视觉变量，不改变按钮位置、术语、操作顺序或功能含义。

## 10. 可访问性与内容规范

1. 正文和关键按钮目标为至少 **4.5:1** 对比度；大字至少 **3:1**。
2. 当前色值尚未逐主题完成 WCAG 对比度认证，正式落地前必须在实际叠加后的背景上检测，而不是只检测变量色值。
3. 透明卡片文字对比度需按最亮和最暗背景分别测试。
4. 鼠标可点击目标建议至少 32 × 32px；触控目标至少 44 × 44px。
5. 状态同时使用文字和图形，不向色觉障碍用户只传递红绿差异。
6. 动画遵循系统“减少动态效果”设置；开启后取消位移和大幅过渡。
7. 主要功能必须可键盘访问，图标按钮必须有可读名称。
8. 错误信息说明“发生了什么、是否产生影响、下一步怎么办”，避免只写“操作失败”。
9. 实例名、路径、Token 等数据保持原始大小写；Token 默认遮挡，复制前可临时显示。
10. 卸载文案必须包含实例名，明确数据目录是否保留。

## 11. GTK / 前端落地映射建议

- 将第 4 节变量映射到统一主题令牌，再由 `GtkCssProvider` 或前端 CSS 注入，避免七份组件样式分别维护。
- 组件只写语义类，例如 `primary-button`、`instance-card`、`status-running`；主题只覆盖变量与材质类。
- 图标使用同一套 SVG 资源，按当前前景色着色；不要导出七套重复 PNG 图标。
- 使用 Pango 字体映射中文、英文和等宽字体，并在目标 Linux 环境重新测量文本宽度。
- 玻璃效果依赖平台合成器；不支持模糊时退化为 `card-solid` 背景，不影响功能。
- 扁平化主题可作为低性能回退方案，关闭模糊、阴影和背景装饰。
- 将 180/200/250/350ms 动效集中定义，遵循系统减少动画设置。
- 主题设置与业务状态分离保存；实例启停结果必须以后端真实状态为准。
